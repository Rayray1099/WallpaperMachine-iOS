## Platform and authorization boundaries

This is an in-app native renderer plus file export. Public iOS APIs do not allow arbitrary continuous third-party Home/Lock Screen rendering or unrestricted other-app audio capture. Author previews, actual engine playback, file conversion, AirCard import and system application are distinct. Only user-authorized Workshop/assets may be downloaded or imported; Wallpaper Engine's licensed shared resources are not redistributed. Personal device screenshots/traces, credentials, the supplied dylib and local injected IPAs stay out of Git.
